# Product roadmap

## Current phase: Website launch

- Production-ready OLED interface.
- Responsive landing page and document studio.
- PDF template preview.
- CSV and Excel parsing.
- Silent dominant-font detection.
- Multiple draggable text fields.
- Professional font and formatting controls.
- Duplicate-field visibility.
- White cover blocks for replacement content.
- PNG and JPEG signatures and logos.
- Drag-to-delete and explicit delete controls.
- Custom output filename patterns.
- Bulk PDF generation and ZIP download.
- Vercel deployment configuration and Web Analytics support.

## Next: Editing depth

- Multi-page field placement.
- Undo and redo.
- Saved browser templates.
- Multiline text and controlled wrapping.
- Date and number formatting.
- Field duplication controls.
- Keyboard-based positioning.
- Improved accessibility testing.
- Optional custom-font upload with licensing safeguards.
