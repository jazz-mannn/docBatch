# Product Roadmap

## Milestone 1: Functional MVP

- PDF template preview.
- CSV and Excel parsing.
- Multiple draggable fields.
- Formatting controls.
- Bulk PDF generation.
- ZIP download.
- Static deployment.

## Milestone 2: Usability

- Multi-page field placement.
- Undo and redo.
- Saved local templates.
- Custom embedded fonts.
- Image, logo, and signature fields.
- Date formatting.
- Text wrapping and multiline fields.
- Improved keyboard accessibility.

## Milestone 3: Commercial release

- User accounts.
- Saved cloud templates.
- Usage limits and metering.
- One-time batch payments.
- Subscription plans.
- Organisation branding.
- QR verification pages.
- Payment and billing records.

## Milestone 4: Business automation

- Email delivery.
- Team workspaces.
- API and webhook access.
- Reusable campaigns.
- Template marketplace.
- Audit history.
